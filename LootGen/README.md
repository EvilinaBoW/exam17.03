# LootGen

**Продвинутая утилита для симуляции и анализа выпадения лута**  
Критически важный инструмент для баланса игры в студии.

## Описание
LootGen симулирует открытие сундуков с разными типами (common/rare/epic).  
Поддерживает 12+ предметов, настраиваемый конфиг, экспорт в CSV и графики вероятностей.  
Идеально подходит для тестирования баланса редких предметов.

## Технологии
- **Python 3.12**
- **rich** — красивый цветной вывод таблиц и прогресс-баров
- **matplotlib** — генерация графиков вероятностей
- **ruff** — статический анализ кода
- **GitHub Actions** — автоматический CI/CD (линтинг при каждом push/PR)
